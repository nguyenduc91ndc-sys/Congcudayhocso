Hướng dẫn sử dụng

Lấy API Key Gemini (miễn phí):

  1. Truy cập Google AI Studio
  2. Đăng nhập tài khoản Google → Nhấn "Create API Key"
  3. Sao chép key và dán vào phần Cài đặt (⚙️)

Lấy API Key Groq (miễn phí):

  1. Truy cập Groq Console
  2. Đăng nhập/đăng ký → Nhấn "Create API Key"
  3. Sao chép key và dán vào phần Cài đặt (⚙️)
