# Trò chơi kéo - thả phân loại

Game HTML độc lập cho trẻ mầm non.

## Cách chạy

Mở file `index.html` bằng trình duyệt.

## Tính năng

- Kéo thả bằng chuột hoặc màn hình cảm ứng.
- 4 chủ đề: động vật, phương tiện, rau quả, hình dạng.
- Hình kéo thả dùng bộ icon PNG 3D Microsoft Fluent Emoji.
- Âm thanh đúng/sai tạo bằng Web Audio.
- Âm thanh hướng dẫn khi bấm `Bắt đầu` dùng file WAV trong `assets/sounds/guide.wav`.
- Âm thanh chiến thắng khi hoàn thành dùng file MP3 thật trong `assets/sounds/victory.mp3`.
- Chấm điểm, đếm số câu đúng.
- Hiệu ứng sao, rung khi sai, confetti khi đúng và khi hoàn thành.
