Xuất HTML & Chia sẻ Online

Xuất file HTML chứa toàn bộ ảnh + thông tin ở chất lượng cao nhất.

📋 Hướng dẫn đưa lên mạng:
① Bấm nút trên để tải file HTML
② Vào app.netlify.com/drop ↗ (miễn phí)
③ Kéo thả file HTML vào trang Netlify
④ Copy link Netlify → dán vào ô bên dưới → Tạo QR!

✅ Gửi QR này cho PH — quét là xem kỉ yếu ngay!
