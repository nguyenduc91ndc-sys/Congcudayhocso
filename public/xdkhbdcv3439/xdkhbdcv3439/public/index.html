API Key

Hướng dẫn lấy API Key Gemini và Groq

Chọn đúng nhà cung cấp ở ô bên cạnh, dán API Key vào khung nhập, bấm Lưu rồi bấm Test để kiểm tra trước khi tạo bài.

Gemini Khuyên dùng khi có ảnh hoặc PDF
  1. Vào Google AI Studio và đăng nhập tài khoản Google.
  2. Chọn Create API key hoặc Get API key.
  3. Chọn dự án Google Cloud nếu hệ thống yêu cầu.
  4. Sao chép key bắt đầu bằng AIza.
  5. Quay lại phần mềm, chọn Gemini, dán key, bấm Lưu và Test.
Mở trang lấy Gemini API Key
Groq Nhanh, phù hợp tạo nội dung từ chữ/ảnh
  1. Vào Groq Console và đăng nhập hoặc tạo tài khoản.
  2. Mở mục API Keys trong bảng điều khiển.
  3. Bấm Create API Key để tạo key mới.
  4. Sao chép key bắt đầu bằng gsk_.
  5. Quay lại phần mềm, chọn Groq, dán key, bấm Lưu và Test.
Mở trang lấy Groq API Key

Không chia sẻ API Key cho người khác. Nếu key bị lộ, hãy vào trang quản lý key để xóa key cũ và tạo key mới.
